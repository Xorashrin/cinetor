Cinetor adapts the modular fullCommonMain plugin runtime, primarily JsBindings.kt.
Changes: no generated Compose UI/TMDB dependencies, official QuickJS runtime,
30-second native interrupt, bounded heap/stack/host output, error propagation,

Cinetor retains the published library and Android Plugin load/resources/settings
ABI, adapts persistent DataStore methods, and adds an independently reviewed
SHA-256-pinned DEX/resource loader. Video actions, WebView/native-library plugins,
and unsupported API versions are rejected, not represented as functioning.
The extension loader is same-UID code execution, not a security sandbox.

CORRESPONDING SOURCE AND BUILD INFORMATION
config/engine-lock.json pins source revisions, binary hashes, original fixture
source hashes, and the dependency profile. tools/fetch_engine_sources.py
--source-bundle --output <new-directory> downloads source archives and emits
SOURCE_RECEIPTS.json without executing or extracting downloaded code. Supply that
bundle, the exact Cinetor app source revision, original fixture source and build
scripts together with every distributed APK. GPL obligations are not satisfied
by an unfulfilled promise to fetch sources later. Exact integration and CI-only
build commands are in docs/NATIVE_ENGINE_PROVENANCE.md.
